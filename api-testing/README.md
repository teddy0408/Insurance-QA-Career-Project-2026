# 자동차보험 API 검증설계

## 폴더 개요

이 폴더는 자동차보험 화면과 업무 흐름을 기준으로 API 검증 관점을 설계한 개인 실습 영역이다.

직장에서 실제 보험사의 API를 직접 실행한 결과가 아니며, 실제 엔드포인트·HTTP 메서드·요청 및 응답 스키마·내부 시스템 구조는 사용하지 않았다.

## 현재 상태

- 경험 구분: 개인 실습
- 진행 상태: API 검증설계 완료
- 실제 API 실행 및 결과: 미수록
- 실제 엔드포인트와 요청·응답 명세: 미확인

## 검증설계 범위

- 차량 기본정보 및 출고 차량 부속정보 조회
- 제조사 차량데이터 조회와 동의 상태
- 운전자 조건과 할인특약 적용
- 보험료 계산과 변경값 반영
- 결제 승인과 계약 생성 상태
- 안전운전 할인특약 배서와 환급 상태
- 조회 실패·재시도·이전값 유지
- 화면·기간계·모니터링 정보의 상태 정합성

## 작성 구분

- 화면·기간계·모니터링 화면에서 직접 확인한 동작은 `직접 확인`으로 구분했다.
- 화면 흐름에서 도출한 요청정보와 결과정보는 `검증 후보`로 구분했다.
- 확인하지 않은 엔드포인트·필드명·HTTP 상태코드·DB 구조·개발 원인은 작성하지 않았다.

## 작성 원칙

- 현업 경험과 개인 실습을 구분한다.
- 실제 보험사의 API 구조처럼 작성하지 않는다.
- 화면에서 확인할 수 없는 내부 처리 구조를 추측하지 않는다.
- 실행하지 않은 테스트를 완료 결과처럼 작성하지 않는다.
- 내부 화면 캡처, 고객정보, 실제 거래정보 및 내부 식별값을 공개하지 않는다.
