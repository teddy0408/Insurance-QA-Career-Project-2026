# 자동차보험 API 테스트

## 폴더 개요

이 폴더는 자동차보험 화면과 업무 흐름을 기준으로 API 요청·응답 검증 방법을 설계하는 개인 실습 영역이다.

직장에서 실제 보험사의 API를 테스트한 경험을 재현한 문서가 아니며, 실제 엔드포인트, 요청·응답 스키마 및 내부 시스템 구조를 사용하지 않는다.

## 현재 상태

- 경험 구분: 개인 실습
- 진행 상태: 준비 중
- 상세 테스트 시나리오 및 실행 결과: 미수록

화면의 입력값·조회값·처리 동작·결과를 충분히 분석한 후 API 요청값과 응답값 후보를 설계할 예정이다.

## 예정 검증 범위

- 화면 입력값과 요청값 후보 연결
- 외부조회 결과와 응답값 후보 분석
- 성공·실패 응답에 따른 화면 반영 결과
- 필수값·형식·업무규칙 오류 처리
- 재시도 시 상태와 데이터 정합성
- 보험료·계약·결제 상태의 일관성
- 개인정보 및 인증정보 노출 위험

## 작성 원칙

- 현업 경험과 개인 실습을 구분한다.
- 실제 보험사의 엔드포인트와 스키마처럼 작성하지 않는다.
- 화면에서 확인할 수 없는 내부 처리 구조를 추측하지 않는다.
- 요청값과 응답값은 실제 구조가 아닌 검증 후보로 표시한다.
- 실행하지 않은 테스트를 완료 결과처럼 작성하지 않는다.
