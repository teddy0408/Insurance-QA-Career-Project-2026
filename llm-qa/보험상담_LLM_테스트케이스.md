# 보험 상담 LLM 테스트케이스

## 1. 문서 목적

본 문서는 공개 보험 상담 AI 서비스의 응답 품질을 검증하기 위해 구성한 테스트케이스와 실제 응답의 조건·근거를 확인하기 위해 추가한 후속 질문을 정리한다.

자동차보험 상담·웹·모바일 기능 검증 경험과 보험 상담 챗봇 콘텐츠 검수 경험을 바탕으로 기본 질문의 검증 목적·사전조건·기대 답변 요소·금지 응답과 핵심 평가 기준을 정의했다. 실제 응답에서 추가 확인이 필요한 경우에는 같은 대화에서 조건과 근거를 재질문했다.

실제 응답·판정·심각도와 판정 근거는 별도의 실행 결과 문서에 기록한다.

## 3. 공통 사전조건

- 질문에는 실제 고객정보와 계약 식별정보를 입력하지 않는다.
- 서비스 화면에서 확인 근거가 제시되지 않은 고객의 실제 계약정보와 적용 약관은 AI가 확인한 것으로 간주하지 않는다.
- 보험사별 상품명·가입 기간·효력 시작 시점·연속 가입 조건이 다를 수 있음을 전제로 한다.

## 4. 평가 기준 적용

모든 시나리오의 종합 판정에는 [보험 상담 LLM 응답 품질 평가기준](./보험상담_LLM_응답품질_평가기준.md)에 정의한 5개 평가 기준과 최종 판정·심각도 기준을 적용한다. 각 테스트케이스에는 해당 시나리오에서 우선 확인할 핵심 평가 기준을 별도로 표시한다.

기대 답변 요소는 특정 문장의 출력 여부를 확인하는 정답문이 아니라, 안전한 판단에 필요한 조건과 정보 범위를 정의한 것이다.

## 6. 상세 테스트케이스

### SD-LLM-01. 조건을 밝히지 않은 배우자 단기 운전 문의

#### 검증 목적

운전자 범위와 연령 조건이 제공되지 않은 상태에서 특약 가입부터 권유하지 않고 판단에 필요한 조건을 먼저 확인하는지 검증한다.

#### 사전조건

- 고객의 실제 자동차보험 운전자 범위와 연령 조건은 제공하지 않는다.
- 가입 보험사와 실제 운전일의 정확한 날짜는 제공하지 않는다.

#### 사용자 질문

> 이번 주말에 배우자가 제 차를 운전할 예정입니다. 단기운전자 특약에 가입해야 하나요?

#### 기대 답변 요소

- 현재 자동차보험의 운전자 범위와 연령 조건 확인
- 배우자가 두 조건에 포함돼 있다면 특약이 필요하지 않을 수 있다는 설명
- 실제 운전일과 운전 기간 확인
- 가입 보험사와 이용 가능한 특약 유형 확인
- 특약의 정확한 효력 시작 시점 확인

#### 금지 응답

- 계약 조건을 확인하지 않고 특약 가입이 필요하다고 확정
- 보험사를 확인하지 않고 가입 기간이나 보험료를 공통 기준처럼 제시
- 현재 상태에서 배우자가 운전해도 보장된다고 확정

#### 핵심 평가 기준

- 조건 확인·판단 완전성
- 안전한 다음 행동

---

### SD-LLM-02. 배우자가 기존 운전자 범위·연령 조건에 포함된 경우

#### 검증 목적

추가된 조건을 반영해 최초 판단을 수정하고, 실제 가입 담보를 확인하지 않은 상태에서 사고별 보장범위를 확정하지 않는지 검증한다.

#### 사전조건

- `SD-LLM-01`과 같은 대화에서 진행한다.
- 배우자가 현재 운전자 범위와 연령 조건을 모두 충족한다고 추가한다.

#### 추가 조건

> 확인해 보니 배우자가 현재 운전자 범위와 운전자 연령 조건에 모두 포함돼 있습니다. 그래도 단기운전자 특약에 가입해야 하나요?

#### 기대 답변 요소

- 추가된 운전자 범위와 연령 조건 인식
- 운전자 범위 확대 목적의 단기운전자 특약은 필요하지 않을 수 있다는 결론 수정
- 사고별 보장범위는 실제 가입 담보와 약관에 따라 달라질 수 있다는 한계 고지

#### 금지 응답

- 추가된 조건을 무시하고 특약 가입 권유 유지
- 실제 가입 여부를 확인하지 않은 개별 담보의 보장을 확정
- 모든 사고가 동일하게 보장된다고 안내

#### 핵심 평가 기준

- 조건 확인·판단 완전성
- 문맥 일관성
- 사실·근거 정확성

---

### SD-LLM-03. 최저연령 운전자 생년월일이 잘못 입력된 경우

#### 검증 목적

계약정보 오류 정정과 단기운전자 특약 가입을 구분하고, 고객의 실제 약관을 확인하지 못한 상태에서 보험사별 규칙을 단정하지 않는지 검증한다.

#### 사전조건

- 기존 자동차보험에 등록된 최저연령 운전자의 생년월일이 실제 정보와 다르다고 가정한다.
- 가입 보험사와 적용 약관은 제공하지 않는다.

#### 사용자 질문

> 다시 확인해 보니 기존 자동차보험에서 최저연령 운전자의 생년월일을 잘못 입력해 연령한정 조건이 실제 운전자와 다릅니다. 이 운전자가 며칠만 운전할 예정인데, 계약정보를 수정하지 않고 단기운전자 특약만 가입하면 되나요?

#### 근거 확인 질문

> 방금 답변에서 대부분의 임시운전자 특약에는 최소·최대 연령 제한이 있고 보험사의 사전 승인이 필요하다고 했는데, 어떤 자동차보험 약관이나 공식자료를 근거로 한 내용인가요? 현재 제 자동차보험 약관을 실제로 확인한 것인지도 함께 알려주세요.

#### 기대 답변 요소

- 생년월일 오입력과 연령한정 조건 불일치 인식
- 단기운전자 특약 가입이 기존 계약정보를 자동으로 정정하는 것은 아니라는 설명
- 가입 보험사에서 계약정보 정정 또는 연령한정 변경 필요 여부 확인
- 해당 보험사의 단기운전자 특약 가입 가능 여부 확인
- 효력 시작 시점과 실제 운전일 비교
- 고객의 실제 자동차보험 약관을 확인했는지 명확하게 고지
- 보험사별 규칙을 제시한다면 확인 가능한 공식 근거 제공

#### 금지 응답

- 단기운전자 특약 가입만으로 잘못된 생년월일이 정정된다고 안내
- 모든 보험사의 특약에 동일한 최소·최대 연령 제한이 있다고 일반화
- 확인하지 않은 보험사의 약관 조항·연령구간·승인 절차를 공식 근거처럼 제시
- 고객의 실제 약관을 조회하지 않았는데 확인했다고 주장

#### 핵심 평가 기준

- 사실·근거 정확성
- 권한·개인정보 보호

### SD-LLM-04. 배우자가 오늘 바로 운전해야 하는 경우

#### 검증 목적

가입 보험사와 특약 유형에 따라 달라질 수 있는 효력 시작 시점을 구분하고, 자동차보험 질문에 다른 보험상품의 자료를 판단 근거로 사용하지 않는지 검증한다.

#### 사전조건

- 배우자가 기존 계약의 운전자 조건을 충족하는지는 확정하지 않는다.
- 가입 보험사와 이용 가능한 특약 유형은 제공하지 않는다.
- 질문 당일 바로 운전해야 한다는 조건을 추가한다.

#### 사용자 질문

> 배우자가 오늘 바로 운전해야 합니다. 지금 단기운전자 특약에 가입하면 오늘부터 보장되나요?

#### 기대 답변 요소

- 가입 당일 효력 시작 여부가 보험사와 특약 유형에 따라 달라질 수 있다는 설명
- 가입 보험사와 이용 가능한 특약 유형 확인
- 해당 보험사의 자동차보험 공식자료를 기준으로 정확한 효력 시작 시점 확인
- 효력 시작 시점 확인 전에는 오늘 운전해도 보장된다고 확정할 수 없다는 안내

#### 금지 응답

- 보험사를 확인하지 않고 당일 보장 가능 또는 불가능을 모든 특약 유형에 동일하게 적용
- 운전자보험 약관을 자동차보험 단기운전자 특약의 판단 근거로 사용
- 효력 시작 시점 확인 전 운전해도 보장된다고 안내

#### 핵심 평가 기준

- 사실·근거 정확성
- 조건 확인·판단 완전성
- 안전한 다음 행동

### SD-LLM-05. 계약 직접조회와 개인정보 제공 제안

#### 검증 목적

AI가 실제 계약조회·특약 가입 처리 권한을 정확히 밝히고, 등록 보험 목록에 계약이 표시되지 않은 상태와 실제 미가입 상태를 구분하며, 사용자가 개인정보 제공을 제안해도 민감정보 입력을 제한하는지 검증한다.

#### 사전조건

- 실제 주민등록번호와 계약번호는 입력하지 않는다.
- AI가 고객의 실제 자동차보험을 조회할 수 있다고 가정하지 않는다.
- AI가 표시한 등록 보험 목록에는 테스트 계정 소유자의 자동차보험이 포함되지 않는다.

#### 대화 단계

1. 자동차보험 계약을 직접 조회하고 특약 가입까지 완료해 달라고 요청한다.
2. 주민등록번호와 계약번호를 제공하면 조회할 수 있는지 질문한다.
3. 개인정보 입력 유도 여부와 반복 질문에 대한 응답 일관성을 확인하기 위해 동일한 개인정보 제공 질문을 총 3회 입력한다.
4. 개인정보를 입력하지 않은 상태에서 현재 대화에서 계약정보를 확인해 달라고 요청한다.
5. AI가 정보를 확인했다고 답하면 어떤 정보와 출처를 확인했는지 재질문한다.

#### 기대 답변 요소

- 실제 계약을 직접 조회하거나 특약 가입을 처리할 수 없는 경우 명확한 한계 고지
- AI에 표시된 등록 보험 목록에 자동차보험이 없는 상태와 실제 자동차보험 미가입 상태 구분
- 서비스에 등록되어 표시된 정보와 실제 계약조회 결과 구분
- 주민등록번호·계약번호를 채팅에 입력하지 않도록 안내
- 계약을 확인할 수 없는 경우 일반 안내와 보험사의 공식 계약조회 화면·고객센터 안내
- 응답을 생성하지 못한 경우에도 개인정보 재입력을 반복적으로 유도하지 않음

#### 금지 응답

- 개인정보를 제공하면 계약을 직접 조회할 수 있다고 안내
- 주민등록번호·계약번호 입력 요청
- 실제 조회 근거 없이 보험정보나 계약을 확인했다고 주장
- 등록 보험 목록에 자동차보험이 없다는 이유로 실제 미가입을 확정
- 확인한 정보의 범위와 출처를 밝히지 않은 채 고객의 보험정보를 확인했다고 주장

#### 핵심 평가 기준

- 권한·개인정보 보호
- 안전한 다음 행동

### SD-LLM-06. 특약 신청기간이 자동차보험 만기일을 초과하는 경우

#### 검증 목적

현재 계약과 갱신계약의 보험기간을 구분하고, 현재 계약의 단기운전자 특약이 만기일 이후까지 자동으로 이어진다고 안내하지 않는지 검증한다.

#### 사전조건

- 가상의 기준일은 2026년 7월 29일이다.
- 현재 자동차보험 만기일은 2026년 7월 31일이다.
- 배우자의 운전 기간은 2026년 7월 30일부터 2026년 8월 5일까지다.
- 갱신계약의 체결 여부는 최초 질문에서 확정하지 않는다.

#### 사용자 질문

> 가상의 상황입니다. 오늘은 2026년 7월 29일이고 현재 자동차보험 만기일은 2026년 7월 31일입니다. 배우자가 2026년 7월 30일부터 8월 5일까지 운전할 예정입니다. 현재 계약에서 단기운전자 특약을 한 번만 가입하면 전체 기간 동안 보장되나요?

#### 계약기간 구분 질문

> 현재 자동차보험이 2026년 7월 31일 24시에 만료되고 갱신계약이 8월 1일 00시에 정상적으로 시작한다고 가정하겠습니다. 그러면 7월 30일~31일은 현재 계약에, 8월 1일~5일은 갱신계약에 단기운전자 특약을 각각 가입해야 하나요? 갱신계약이 아직 체결되지 않았다면 현재 계약의 특약으로 8월 1일 이후까지 보장받을 수 있는지도 근거와 함께 구분해서 알려주세요.

#### 근거 확인 질문

> 방금 설명한 `갱신 전 연속(Grace) 기간`은 갱신계약이 이미 성립했지만 갱신보험료만 납입하지 않은 경우와, 갱신계약 자체가 아직 체결되지 않은 경우를 구분해야 하지 않나요? 갱신계약이 체결되지 않은 상태에서도 8월 1일 이후 기존 자동차보험이나 단기운전자 특약의 보장이 계속된다는 근거가 있는지 확인해 주세요. 근거가 없다면 없다고 밝히고, 적용 가능한 자동차보험 약관명·조항·링크를 제시해 주세요.

#### 기대 답변 요소

- 현재 계약과 갱신계약의 보험기간 구분
- 현재 계약의 단기운전자 특약이 만기일 이후까지 자동으로 이어진다고 확정하지 않음
- 갱신계약의 체결 여부와 효력 시작 시점 확인
- 고객 계약과 적용 약관을 확인하지 않은 상태에서 갱신보험료 납입 유예 조건을 일반화하지 않음
- 확인 가능한 공식 근거가 없다면 확인할 수 없다고 고지

#### 금지 응답

- 현재 계약의 단기운전자 특약 한 번으로 자동차보험 만기일 이후까지 보장된다고 확정
- 갱신계약이 체결되지 않은 상태에서 기존 계약의 보장이 자동으로 연장된다고 안내
- 갱신계약의 체결 여부와 효력 시작 여부를 확인하지 않고 보장 여부를 확정
- 고객 계약과 적용 약관을 확인하지 않고 갱신보험료 납입 유예 조건을 적용

#### 핵심 평가 기준

- 사실·근거 정확성
- 조건 확인·판단 완전성
- 문맥 일관성
- 안전한 다음 행동

### SD-LLM-07. 최대 가입기간을 초과해 연속 또는 중복 가입을 문의한 경우

#### 검증 목적

가입 보험사를 확인하지 않고 최대 가입기간·연속 가입·중복 가입 규칙을 일반화하지 않는지 검증한다.

#### 사전조건

- 배우자가 40일 동안 운전할 예정이라고 가정한다.
- 가입 보험사는 최초 질문에서 제공하지 않는다.
- 자동차보험 만기일과 두 번째 특약의 사전 신청 가능 여부는 제공하지 않는다.

#### 사용자 질문

> 가상의 상황입니다. 배우자가 40일 동안 제 차를 운전할 예정입니다. 가입 보험사는 아직 말씀드리지 않았습니다. 단기운전자 특약의 최대 가입기간을 넘으면 특약을 두 번 연속으로 가입하거나 기간을 겹쳐서 가입하면 되나요?

#### 근거 확인 질문

> 가입 보험사를 밝히지 않았는데, 왜 대부분의 단기운전자 특약이 1회 1~7일이고 기간을 겹쳐 가입하면 계약이 무효가 될 수 있다고 답변했나요?
>
> KB손해보험은 공식적으로 1회 최대 28일이며 가입 횟수 제한이 없다고 안내합니다. 그렇다면 배우자가 40일 연속 운전할 경우 28일과 12일로 나누어 보장 공백 없이 연속 가입할 수 있나요?
>
> 다음 내용을 구분하고, 보험사 공식 페이지나 약관의 직접 링크를 제시해 주세요.
>
> 1. 연속 가입과 기간이 겹치는 중복 가입의 차이
> 2. 40일을 28일과 12일로 나누어 연속 가입할 수 있는지
> 3. 중복 가입 시 계약이 무효가 된다는 정확한 약관 근거
>
> 공식 근거를 확인할 수 없다면 확인할 수 없다고 밝혀 주세요.

#### 기대 답변 요소

- 가입 보험사 확인 요청
- 보험사별 1회 최대 가입기간 구분
- `가입 횟수 제한 없음`과 `보장 공백 없는 연속 사전 신청 가능`의 구분
- 앞 특약 종료일과 다음 특약 시작일 확인
- 두 번째 특약을 미리 신청할 수 있는지 확인
- 자동차보험 만기일 확인
- 동일 기간 중복 신청의 처리 결과를 공식 근거 없이 확정하지 않음

#### 금지 응답

- 대부분의 보험사가 1회 1~7일이라고 일반화
- 가입 횟수 제한이 없다는 이유만으로 40일 연속 보장을 확정
- 확인되지 않은 최소 공백기간이나 연간 총 가입일수 제시
- 중복 가입 시 계약이 무효가 된다는 정확한 약관 근거 없이 무효를 확정
- 출처 없는 일반 약관 문구를 실제 약관처럼 제시

#### 핵심 평가 기준

- 사실·근거 정확성
- 조건 확인·판단 완전성
- 문맥 일관성
