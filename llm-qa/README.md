# 보험 상담 LLM QA

## 폴더 개요

이 폴더는 공개 보험 상담 AI 서비스의 응답 품질과 위험을 평가한 개인 실습 결과를 관리한다.

자동차보험 상담·웹·모바일 기능 검증 경험과 보험 상담 챗봇 콘텐츠 검수 경험을 바탕으로 평가 기준과 테스트케이스를 설계하고, 공개 서비스에서 질문을 실행해 실제 응답을 판정했다.

보험 상담 AI가 확인 가능한 계약정보 범위에 따라 일반 안내·추가 조건 확인·공식 조회 또는 상담 연결을 구분하고, 확인하지 못한 가입·보장·효력 시작 시점을 단정하지 않는지 5개 평가 기준으로 검증했다.

---

## 용어 사용 기준

- `단기운전자 특약`: 이 폴더에서 일정 기간 운전자 범위를 변경하는 관련 특약 유형을 통칭하는 표현
- `단기운전자 확대특약`: 기존 운전자 범위·연령 제한을 일정 기간 확대하는 특약 유형
- `당일 효력 특약`: 가입 당일 효력이 시작될 수 있는 자동차보험 특약 유형을 일반화한 표현으로, 특정 보험사의 공식 상품명이 아님
- `임시운전자 특약`: AI 응답 또는 보험사 공식 안내에서 해당 명칭을 사용한 경우 원문에 따라 표기

보험사별 실제 상품명과 가입 기간·효력 시작 시점은 다를 수 있으므로, 특정 보험사의 명칭이나 조건을 다른 보험사에 동일하게 적용하지 않는다.

## 실무 경험과 개인 실습의 연결

| 구분 | 수행 내용 | LLM QA와의 연결 |
| --- | --- | --- |
| 보험 상담 챗봇 콘텐츠 검수 | 등록된 공통 답변의 보험 정보 정확성·업무 기준 최신성·적용 조건을 검수하고 부정확하거나 적용이 종료된 내용을 현행화 | 사실 정확성·업무 기준 최신성·적용 조건 평가의 근거 |
| 단기운전자 확대특약 기능 검증 | 모바일 챗봇 경로에서 차량번호·이용 시작일·이용 기간 입력부터 보험료 계산·결제까지의 흐름과 가입 기간 유효성을 검증([END-001](../test-cases/END-001_단기운전자_확대특약_가입기간.md)) | 계약 상태·가입 기간·효력 시작 시점 시나리오의 도메인 근거 |
| 개인 LLM QA 실습 | 공개 보험 상담 AI를 사실·근거 정확성, 조건 확인·판단 완전성, 문맥 일관성, 권한·개인정보 보호, 안전한 다음 행동의 5개 기준으로 평가 | 실무에서 확인한 검증 관점을 생성형 응답 평가로 확장 |

## 실행 결과 요약

| 판정 | 결과 |
| --- | --- |
| PASS | 0건 |
| CONDITIONAL PASS | 1건 |
| FAIL | 6건 |

7건은 조건 변경, 계약기간·가입기간 경계, 계약조회 권한과 근거 오류 가능성이 높은 상황을 의도적으로 선정한 위험 기반 시나리오다. 결과는 해당 시나리오에서 관찰한 응답에 한정하며, 서비스 전체의 정확도나 실패율을 의미하지 않는다.

세부 실행 조건과 확인 한계는 [단기운전자 특약 조건 변경·계약정보 미확인 상황 LLM 응답 검증](./단기운전자_특약_조건변경_LLM_응답_검증.md)에 기록했다.
