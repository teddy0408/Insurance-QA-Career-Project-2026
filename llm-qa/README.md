# 보험 상담 LLM QA

## 폴더 개요

이 폴더는 공개 보험 상담 AI 서비스의 응답 품질과 위험을 평가한 개인 실습 결과를 정리한다.

보험사에서 LLM QA를 수행한 실무 경험이 아니며, 자동차보험 상담과 QA 업무 경험을 바탕으로 평가기준과 기대답변을 설계한 후 공개 서비스에서 직접 질문을 실행하고 결과를 판정했다.

실제 고객정보와 계약정보는 입력하지 않았으며, 서비스의 내부 프롬프트·검색 구조·데이터베이스·개발 원인은 확인하지 않았다.

## 포함 문서

### [단기운전자 특약 조건변경·계약정보 미확인 상황 LLM 응답 검증](./단기운전자_특약_조건변경_LLM_응답_검증.md)

단기운전자 특약 문의에서 계약정보와 운전자 조건이 추가·변경될 때 AI가 기존 판단을 수정하고, 확인된 근거 범위에서 안전하게 안내하는지를 검증했다.

주요 검증 영역은 다음과 같다.

- 운전자 범위·연령 확인 전 특약 권유
- 변경된 조건을 반영한 기존 결론 수정
- 최저연령 운전자 생년월일 오입력
- 당일 운전과 특약 효력시점
- 자동차보험과 운전자보험의 출처 구분
- 개인정보 보호와 계약조회 권한
- 자동차보험 만기일을 넘는 특약기간
- 보험사별 최대 가입기간과 연속·중복 가입

## 실행 결과

2026년 7월 29일 공개 보험 상담 AI 서비스 1종에서 대표 시나리오 7건을 실행했다.

- `PASS`: 0건
- `CONDITIONAL PASS`: 2건
- `FAIL`: 5건
- 합계: `0 + 2 + 5 = 7건`

심각도는 `상` 1건, `중` 6건, `하` 0건으로 분류했으며, 합계는 `1 + 6 + 0 = 7건`이다.

이 결과는 선정한 시나리오 7건의 관찰 결과이며, 해당 AI 서비스 전체의 오류율이나 품질 수준을 의미하지 않는다.

## 평가 기준

- 사실 정확성
- 조건 완전성
- 근거 없는 단정 방지
- 조건변경에 따른 답변 일관성
- 개인정보 보호
- 계약조회 권한 경계
- 출처 관련성
- 출처 추적성
- 안전한 상담 연결

---

## 작성 원칙

- 현업 경험과 개인 실습을 구분한다.
- 실제 고객정보와 보험사 내부정보를 사용하지 않는다.
- 보험약관과 보험사 공식 안내자료로 확인할 수 있는 기준을 사용한다.
- 실제 응답, 공식 근거, 평가자의 판단을 구분한다.
- 실행하지 않은 평가를 완료 결과처럼 작성하지 않는다.
- 공식 근거를 확인하지 못한 내용은 추정하지 않는다.
- 특정 서비스와 보험사의 결과를 전체 서비스의 품질로 일반화하지 않는다.
