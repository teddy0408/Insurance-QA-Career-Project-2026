# 보험 상담 LLM QA

## 폴더 개요

이 폴더는 보험 상담 LLM의 응답 품질과 위험을 평가하는 개인 실습 영역이다.

직장에서 실제 LLM QA를 수행한 경험을 재현한 문서가 아니며, 공개적으로 구성한 보험 상담 질문과 평가 기준을 사용해 테스트할 예정이다.

## 현재 상태

- 경험 구분: 개인 실습
- 진행 상태: 준비 중
- 상세 평가 시나리오 및 실행 결과: 미수록

보험 업무규칙을 기준으로 평가 질문과 기대 응답 조건을 먼저 설계한 후 실제 응답 결과를 기록할 예정이다.

## 예정 평가 범위

- 보험 업무정보의 정확성
- 답변 근거의 명확성
- 동일 조건 질문에 대한 응답 일관성
- 정보가 부족한 질문에 대한 확인 요청
- 확인할 수 없는 내용의 추측 방지
- 가입·보상 결과를 단정하는 응답 방지
- 개인정보 입력 유도 및 노출 위험
- 답변 거절이 필요한 질문의 처리
- 고객이 이해할 수 있는 안내 문장

## 작성 원칙

- 현업 경험과 개인 실습을 구분한다.
- 실제 고객정보와 보험사 내부정보를 사용하지 않는다.
- 보험약관과 공식 안내자료로 확인할 수 있는 평가 기준을 사용한다.
- 정확성·근거성·일관성·안전성을 구분해 평가한다.
- 실행하지 않은 평가를 완료 결과처럼 작성하지 않는다.
- 평가 결과를 근거 없이 수치화하지 않는다.
