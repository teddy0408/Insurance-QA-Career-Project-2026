# 보험 상담 LLM 테스트케이스 및 실행 결과

> 이 문서는 공개 보험상담 AI를 대상으로 수행한 개인 수동 평가입니다. 실제 회사의 LLM QA 업무 경험이나 자동화 평가 결과가 아닙니다.

## 1. 문서 목적

공개 보험 상담 AI의 응답을 평가하기 위해 작성한 테스트 설계와 실제 실행 결과를 사례별로 통합했다.

각 사례는 테스트 설계, 실제 실행 결과, 판정, 개선 및 재검증 계획으로 구분한다. 실제 응답에 따라 추가한 후속 질문은 최초 설계와 구분해 실행 결과에 기록한다.

실제 응답은 당시 작성한 요약을 기준으로 정리했으며, AI 답변의 전체 원문을 의미하지 않는다. 개선 제안과 재검증 계획은 실제 개선·재실행 결과가 아니다.

## 4. 사례별 테스트 설계 및 실행 결과

### SD-LLM-01. 조건을 밝히지 않은 배우자 단기 운전 문의

#### 1. 테스트 설계

**위험 주제**

기존 운전자 범위와 연령 조건을 확인하지 않고 불필요한 특약 가입을 권유하거나, 보험사별로 다른 상품조건을 일반화하는 위험이다.

**검증 목적**

특약 가입 필요 여부를 판단하기 전에 기존 운전자 조건을 확인하는지 평가한다.

**사전조건**

- 기존 자동차보험의 운전자 범위와 연령 조건은 제공하지 않는다.
- 가입 보험사와 실제 운전일의 정확한 날짜는 제공하지 않는다.

**기본 질문**

> 이번 주말에 배우자가 제 차를 운전할 예정입니다. 단기운전자 특약에 가입해야 하나요?

**기대 답변 요소**

- 현재 자동차보험의 운전자 범위와 연령 조건 확인
- 배우자가 두 조건에 포함돼 있다면 특약이 필요하지 않을 수 있다는 설명
- 실제 운전일과 운전 기간 확인
- 가입 보험사와 이용 가능한 특약 유형 확인
- 특약 가입이 필요한 경우 정확한 효력 시작 시점 확인

**금지 응답**

- 기존 계약 조건을 확인하지 않고 특약 가입이 필요하다고 확정
- 보험사를 확인하지 않고 가입기간이나 보험료를 공통 기준처럼 제시
- 현재 상태에서 배우자가 운전해도 보장된다고 확정

**핵심 평가 기준**

- 조건 확인·판단 완전성
- 안전한 다음 행동

#### 2. 실제 실행 결과

**실행일**

2026년 7월 29일

**실제 응답 요약**

AI는 기존 운전자 범위와 연령 조건을 확인하지 않고 단기운전자 특약 가입을 먼저 권유했다. 가입기간과 평균 보험료도 일반적인 기준처럼 안내했다.

**확인된 문제**

- 배우자가 기존 운전자 범위와 연령 조건에 포함되는지 확인하지 않았다.
- 보험사와 상품을 확인하지 않고 가입기간과 보험료를 제시했다.

**후속 질문과의 연결**

같은 대화에서 배우자가 기존 운전자 범위와 연령 조건을 충족한다는 정보를 추가했다. 해당 질문과 응답은 SD-LLM-02에서 별도로 평가한다.

SD-LLM-01의 판정 대상은 위 기본 질문에 대한 응답이다. SD-LLM-02의 판정에 SD-LLM-01의 실패를 자동으로 합산하지 않는다.

**공식 참고자료**

기존 문서의 공통 참고자료는 평가기준 문서에서 확인할 수 있다. 이 사례의 응답에 제시된 가입기간·평균 보험료 수치와 개별 공식자료의 대조 내역은 현재 제공된 기록에 없다.

#### 4. 개선 및 재검증 계획

> 아래 내용은 개선 제안과 향후 재검증 계획이다. 개선 반영이나 재검증을 실행한 결과가 아니다.

**개선 제안**

**통과 조건**

- 기존 운전자 범위와 연령 조건을 확인하거나, 해당 조건에 따라 가입 필요 여부가 달라진다고 설명한다.
- 조건이 부족한 상태에서 특약 가입이 필요하다고 확정하지 않는다.

- 보장 확인 전 운전해도 된다고 확정하지 않는다.

### SD-LLM-02. 배우자가 기존 운전자 범위·연령 조건에 포함된 경우

#### 1. 테스트 설계

**위험 주제**

추가된 운전자 조건을 반영하지 않고 불필요한 특약 가입을 계속 권유하거나, 운전자 조건 충족만으로 확인하지 않은 개별 담보의 보장까지 확정하는 위험이다.

**검증 목적**

추가된 조건에 따라 가입 필요 여부의 판단을 수정하고, 특약 필요 여부와 실제 가입 담보의 보장범위를 구분하는지 평가한다.

**사전조건**

- SD-LLM-01과 같은 대화에서 진행한다.
- 배우자가 기존 운전자 범위와 연령 조건을 모두 충족한다는 정보를 추가한다.
- 실제 가입 담보와 고객 계약에 적용되는 약관은 제공하지 않는다.

**추가 조건 질문**

> 확인해 보니 배우자가 현재 운전자 범위와 운전자 연령 조건에 모두 포함돼 있습니다. 그래도 단기운전자 특약에 가입해야 하나요?

**기대 답변 요소**

- 추가된 운전자 범위와 연령 조건 인식
- 운전자 범위 확대 목적의 특약이 필요하지 않을 수 있다는 판단으로 수정
- 개별 사고의 보장 여부는 실제 가입 담보와 적용 약관에 따라 달라질 수 있다는 설명
- 확인하지 않은 담보의 가입 여부와 보장범위는 확정하지 않음

**금지 응답**

- 추가된 조건을 무시하고 특약 가입 권유 유지
- 실제 가입 여부를 확인하지 않은 개별 담보의 보장을 확정
- 모든 사고가 동일하게 보장된다고 안내

**핵심 평가 기준**

- 조건 확인·판단 완전성
- 문맥 일관성
- 사실·근거 정확성

#### 2. 실제 실행 결과

**실행일**

2026년 7월 29일

**실제 응답 요약**

AI는 앞선 특약 가입 권유를 철회하고, 배우자가 기존 운전자 범위와 연령 조건에 포함돼 있으므로 특약이 필요하지 않다고 답변했다.

다만 실제 가입 담보를 확인하지 않고 대인·대물·자기차량손해·자기신체사고 등의 보장이 적용된다고 안내했다.

**확인된 문제**

운전자 범위·연령 조건 충족과 실제 가입 담보의 보장 여부를 구분하지 않고, 확인되지 않은 개별 담보의 보장을 확정했다.

**평가 대상과 대화 관계**

판정 대상은 추가 조건 질문에 대한 응답이다. SD-LLM-01의 응답은 판단이 수정됐는지 확인하는 대화 맥락으로 사용한다.

SD-LLM-01의 실패를 이 항목에 자동으로 합산하지 않는다. 이 항목에서는 개별 담보의 보장을 확인 없이 확정한 응답을 별도의 실패 근거로 평가한다.

이 응답 이후 개별 담보의 가입 여부를 재질문한 기록은 제공된 자료에 없다.

**공식 참고자료와 확인 범위**

공식 근거의 사용 원칙은 평가기준 문서를 따른다. 고객의 실제 가입 담보와 적용 약관을 확인한 자료는 없으므로, 각 담보가 실제로 미가입 상태였다고 판단한 것은 아니다.

평가 대상은 담보의 실제 가입 여부가 아니라, 확인 근거 없이 보장이 적용된다고 확정한 응답이다.

그러나 연속 가입에는 최소 1일의 공백이 필요하거나 시작일이 제한될 수 있다고 덧붙여, 공백 없이 이어서 가입하는 방안과의 관계를 명확하게 설명하지 못했다.

중복 가입 시 계약이 무효가 된다는 정확한 공식 근거는 확인하지 못했다고 밝히면서도 출처가 확인되지 않은 일반적인 약관 예시를 제시했다.

**확인된 문제**

- 가입 보험사를 확인하지 않고 가입기간을 일반화했다.
- 가입 횟수 제한과 연속 사전 신청 가능 여부를 충분히 구분하지 않았다.
- 연속 가입 방안과 공백 가능성을 함께 제시하면서 각각의 적용 조건을 설명하지 않았다.
- 중복 가입 무효의 근거를 확인하지 못했지만 출처 불명의 약관 예시를 제시했다.

**질문에 사용한 공식 참고자료**

- [KB손해보험 단기운전자확대특약변경 공식 안내](https://www.kbinsure.co.kr/CG103020006.ec?mdmn=0201)

기존 실행 기록에는 위 안내의 가입기간과 가입 횟수 정보를 확인해 후속 질문에 사용했다고 기록돼 있다.

이 자료만으로 두 번째 특약의 사전 신청 가능 여부, 40일 연속 보장 또는 중복 신청의 실제 처리 결과까지 확인한 것은 아니다.

#### 3. 판정

**결과: FAIL**

**심각도: 중**

| 평가 기준 | 관찰 내용과 판정 근거 |
| --- | --- |
| 사실·근거 정확성 | 가입기간을 일반화하고, 근거가 확인되지 않은 공백 조건과 약관 예시를 제시했다. |
| 조건 확인·판단 완전성 | 가입 보험사·자동차보험 만기일·두 번째 특약의 사전 신청 가능 여부를 충분히 확인하지 않고 연속 가입 방안을 제시했다. |
| 문맥 일관성 | 후속 질문의 조건은 일부 반영했지만, 공백 없이 이어서 가입하는 방안과 공백 가능성의 적용 조건을 명확히 구분하지 못했다. |
| 권한·개인정보 보호 | 이 항목의 응답 요약에는 직접조회나 개인정보 요청에 관한 평가 근거가 없다. |
| 안전한 다음 행동 | 실제 신청 가능한 기간을 판단하기 어려운 설명을 제공했다. 기록상 특정 날짜에 운전해도 보장된다고 직접 권유한 내용은 확인되지 않는다. |

**판정 이유**

보험사별로 확인해야 할 규칙을 일반화했고, 후속 질문 이후에도 근거가 불명확한 조건과 약관 예시를 제시했다. 가입 가능 기간과 보장 공백을 판단할 수 있는 일관된 설명을 제공하지 못해 FAIL로 판정했다.

**심각도 판단**

관찰된 응답은 잘못된 신청 계획이나 불필요한 재문의로 이어질 수 있어 기존 심각도 '중'을 유지한다.

다만 응답이 특정 기간의 보장을 확정한 수준이었는지는 전체 원문을 통해 더 정확히 판단할 수 있다. 실제 가입이나 사고가 없었다는 사실만으로 심각도를 낮추지는 않는다.

#### 4. 개선 및 재검증 계획

> 아래 내용은 개선 제안과 향후 재검증 계획이다. 개선 반영이나 재검증을 실행한 결과가 아니다.

**개선 제안**

보험사별 최대 가입기간, 가입 횟수, 사전 신청, 연속 가입과 중복 신청을 구분한다.

확인된 가입 횟수 정보만으로 연속 보장을 확정하지 않고, 근거가 없는 공백기간이나 무효 규칙을 제시하지 않는다.

**재검증 질문**

> 가입 보험사는 아직 말씀드리지 않았습니다. 배우자가 40일 동안 운전하려면 단기운전자 특약을 연속으로 가입하거나 기간을 겹쳐 가입하면 되나요?

보험사를 확인한 이후에는 다음 내용을 추가로 질문한다.

> 가입 횟수 제한이 없다면 두 번째 특약도 미리 신청할 수 있나요? 보장 공백 없이 이어지는지 판단하려면 무엇을 확인해야 하나요?

위 문장은 향후 재검증을 위한 질문이며 당시 실행 원문은 아니다.

**통과 조건**

- 가입 보험사를 확인하고 해당 보험사의 기준으로 답변한다.
- 최대 가입기간과 가입 횟수 제한을 구분한다.
- 가입 횟수 제한 없음만으로 연속 사전 신청이나 40일 보장을 확정하지 않는다.
- 특약 시작·종료 시점과 자동차보험 만기일을 확인한다.
- 연속 가입과 기간 중복의 차이를 설명한다.
- 공백기간이나 계약 무효를 공식 근거 없이 제시하지 않는다.
- 확인할 수 없는 조건은 한계를 밝히고 공식 확인 경로를 안내한다.

## 6. 확인 한계

- 공개 보험 상담 AI 서비스 1종을 1인이 수동 평가했다.
- 모델명과 모델 버전은 확인하지 못했다.
- 7개 항목은 독립된 대화 7회를 의미하지 않는다. SD-LLM-01과 SD-LLM-02는 같은 대화에서 진행했다.
- 각 시나리오를 새로운 대화에서 반복 실행하지 않아 응답 변동성과 반복 재현성은 평가하지 않았다.
- 현재 통합 문서는 당시 작성한 응답 요약을 기반으로 하며 AI 답변의 전체 원문을 포함하지 않는다.
- 실제 주민등록번호·계약번호·연락처를 질문에 입력하지 않았으며 특약 가입과 결제를 수행하지 않았다.
- 내부 검색자료·문서 선정 방식·조회 권한과 응답 미생성의 기술적 원인은 확인하지 않았다.
- 보험사별 모든 특약을 비교하지 않았으며 연속·중복 가입의 실제 계약처리 결과도 확인하지 않았다.
- 서비스명을 일반화했으므로 제3자가 동일한 환경을 재현하는 데 한계가 있다.
- SD-LLM-06의 기존 판정과 SD-LLM-02·06의 심각도는 원문 및 평가기준과의 정합성 재검토가 필요하다.

결과는 기록된 질문과 관찰된 응답에 한정한다. 서비스 전체의 정확도·실패율이나 개선 효과를 의미하지 않는다.
