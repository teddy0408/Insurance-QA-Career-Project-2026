# 자동차보험 결함 보고서

## 폴더 개요

이 폴더는 자동차보험 갱신가입과 계약변경 업무에서 실제로 확인한 대표 결함 2건을 관리한다.

고객 문의 또는 테스트 요청을 바탕으로 발생 조건, 기대 결과와 실제 결과, 고객·계약 영향 및 수정 후 확인 범위를 정리했다.

## 작성 기준

- 직접 확인하거나 재현한 결과와 수정 후 확인 범위만 기록한다.
- 기대 결과와 실제 결과, 실제 발생 결과와 잠재 영향을 구분하고, 확인하지 않은 내부 원인은 추정하지 않으며 식별 정보는 제외한다.

## 테스트케이스와의 연결 관계

| 대상 | 연결 관계 |
| --- | --- |
| `BUG-001`·`VEH-002` | 동일한 차량 부속정보 중복 사례다. `VEH-002`는 검증 목적·기대 동작·절차와 회귀 범위를, `BUG-001`은 오류 재현·영향과 수정 후 확인 결과를 중심으로 작성했다. |
| `BUG-002`·`END-001` | `BUG-002`는 핵심 테스트케이스 5건에 포함되지 않은 별도 대표 결함이다. `BUG-002`는 실시간 단기운전자 특약의 계약 효력 상태를, `END-001`은 단기운전자 확대특약의 가입 기간 중복과 계약 개시일 경계를 다룬다. 두 사례는 상품 유형·확인 경위·검증 조건이 서로 다르다. |

관련 테스트케이스는 [자동차보험 핵심 테스트케이스](../test-cases/README.md)에서 확인할 수 있다.
