# 자동차보험 결함 보고서

## 폴더 개요

이 폴더는 자동차보험 가입 및 계약변경 과정에서 실제 업무 중 확인한 오류를 결함 보고서 형식으로 정리한 포트폴리오 문서를 관리한다.

특정 보험사의 내부 시스템을 설명하기 위한 문서가 아니며, 요구사항과 실제 동작의 차이, 재현 조건, 고객 및 업무 영향, 수정 후 확인 결과를 중심으로 작성했다.

특정 보험사명, 내부 시스템명, 실제 고객정보, 차량정보, 보험료 및 외부업체명은 일반화했다. 직접 확인하지 않은 개발 원인과 내부 시스템 구조는 작성하지 않았다.

## 작성 기준

- 실제 업무에서 확인한 오류만 결함 사례로 작성했다.
- 요구사항과 실제 결과의 차이를 기준으로 작성했다.
- 재현 조건, 재현 절차, 기대결과 및 실제결과를 구분했다.
- 직접 확인한 고객 및 업무 영향만 작성했다.
- 확인하지 않은 개발 원인과 내부 시스템 구조는 추측하지 않았다.
- 수정 후 확인한 내용은 실제 재검증 범위까지만 작성했다.
- 특정 보험사와 고객을 식별할 수 있는 정보는 제외했다.

## 공통 작성 항목

각 결함 보고서는 다음 항목을 기준으로 작성한다.

- `Summary`
- `Environment`
- `Precondition`
- `Steps to Reproduce`
- `Expected Result`
- `Actual Result`
- `Severity`
- `Priority`
- `Customer Impact`
- `QA Note`

## 테스트케이스와의 관계

테스트케이스와 결함 보고서는 일대일로 구성하지 않았다.

[test-cases](../test-cases/README.md)에는 업무규칙과 검증 절차를 보여주는 핵심 테스트케이스를 수록하고, 이 폴더에는 실제 오류 중 재현 절차와 영향을 별도로 보여줄 필요가 있는 대표 결함만 수록했다.

`BUG-001`은 핵심 테스트케이스 문서의 `VEH-002`와 같은 사례다. `BUG-002`는 핵심 테스트케이스 4건에는 포함하지 않고 별도의 대표 결함 보고서로 유지했다.
