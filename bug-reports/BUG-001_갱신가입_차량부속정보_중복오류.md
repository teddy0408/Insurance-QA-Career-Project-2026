# BUG-001. 갱신가입 시 차량 부속정보 중복으로 보험료 계산 단계 진행 불가

## Environment

| 항목 | 내용 |
| --- | --- |
| 확인 경위 | 테스트 요청 검증 중 직접 발견 |
| 오류 확인 환경 | 테스트계 |
| 수정 후 확인 환경 | 테스트계·운영계 |
| 확인 환경·채널 | 테스트계·운영계 / PC 웹·모바일 웹·모바일 앱 |
| 연계 확인 | 기간계·모니터링 로그 |
| 대상 업무 | 자동차보험 갱신가입·자동차정보 |
| 공유 방식 | Redmine·메신저를 통해 발생 조건과 영향 범위를 개발 담당자·관련 업무 담당자에게 공유 |

## Precondition

- 자동차보험 갱신가입이 가능한 계약이 존재한다.
- 기존 계약에 고객이 직접 입력한 할인부속 A가 존재한다.
- 외부 차량정보 조회 결과에도 동일한 할인부속 A가 존재한다.

## Steps to Reproduce

1. 기존 입력 할인부속 A가 존재하는 계약으로 갱신가입을 시작한다.
2. 자동차 정보 화면에서 외부 차량정보 조회를 실행하고 동일한 할인부속 A가 조회되는지 확인한다.
3. 중복 정보 조정 화면에서 기존 입력 할인부속을 제외하고 외부 조회 할인부속만 유지한다.
4. 중복 정보 조정을 완료하고 총차량가액을 확정한다.
5. 다음 단계를 선택해 안내 팝업을 확인한 뒤 다시 다음 단계로 진행한다.

## Expected Result

- 외부 조회 할인부속을 기준으로 동일 할인부속이 하나만 유지돼야 한다.
- 중복 정보 조정 결과와 총차량가액이 정상 반영돼 안내가 반복되지 않고 보험료 계산 단계로 진행돼야 한다.

## Actual Result

기존 입력 할인부속을 제외하고 외부 조회 할인부속만 유지한 뒤 다음 단계를 선택했으나, `부속정보를 확인해 주세요` 팝업이 반복 표시됐고 보험료 계산 단계로 진행할 수 없었다.

## 결함 등급

| 구분 | 판단 | 근거 |
| --- | --- | --- |
| Severity | `Major` | 동일 할인부속이 중복된 갱신계약에서 보험료 계산 단계로 진입할 수 없어 가입 흐름이 중단됨 |
| Priority | `High` | 테스트계의 PC 웹과 모바일에서 재현됐으며 운영 이관 전 수정과 회귀검증이 필요함 |

> 결함 등급은 공개 포트폴리오 작성 기준으로 재구성한 판단이며 실제 사내 분류값을 의미하지 않는다.

## Potential Customer Impact

- 고객이 갱신보험료를 확인하거나 온라인 갱신가입을 완료하지 못할 수 있다.
- 부속정보를 다시 조정해도 안내가 반복돼 가입을 계속 진행하지 못할 수 있다.

## 수정 후 확인 결과

| 구분 | 확인 환경 | 확인 결과 |
| --- | --- | --- |
| 수정 후 재검증 | 테스트계 | 외부 조회 할인부속을 우선 적용하고 동일 할인부속이 하나만 유지되는지 확인했다. 외부 조회 할인부속 제거 제한, 안내 팝업 반복 미발생, 보험료 계산 단계 정상 진입과 보험료 계산을 확인했다. |
| 회귀검증 | 테스트계 | 기타부속 선택 해제와 가액 수정, 청약내용, 결제·가입 완료를 확인했다. 기간계에서는 최종 부속정보와 보험료를 확인하고, 모니터링 로그에서는 부속정보 중복이 발생하지 않았는지 확인했다. |
| 운영 이관 후 확인 | 운영계 | PC 웹·모바일에서 동일 할인부속 중복 조건을 다시 확인했다. 외부 조회 할인부속 하나만 유지되고 안내 팝업이 반복되지 않으며 보험료 계산 단계에 정상 진입하는지 확인했다. 운영계 결제·가입 완료는 확인 범위에 포함하지 않았다. |

## 확인 한계

- 개발 원인과 DB 저장값은 확인하지 않았다.

## QA Note

팝업이 반복되지 않는지만으로 수정 완료를 판단하지 않았다. 부속정보는 총차량가액·보험료·청약정보에 연결되므로, 테스트계에서 동일 부속의 중복 해소와 함께 기타부속 수정, 보험료 계산, 청약·결제·가입 완료 및 기간계 최종 정보를 회귀검증했다.
