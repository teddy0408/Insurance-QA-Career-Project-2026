# BUG-002. 보험 효력 개시 전 계약에서 실시간 단기운전자 특약 가입 가능 오류

## Environment

| 항목 | 내용 |
| --- | --- |
| 확인 경위 | 고객센터 문의 |
| 최초 직접 확인 환경 | 테스트계·운영계 |
| 수정 후 확인 환경 | 테스트계·운영계 |
| 확인 채널 | 모바일 웹·모바일 앱 |
| PC 웹 | 신청 경로가 없어 기능 검증 제외 |
| 연계 확인 | 테스트계 배서계약·기간계 배서내역, 운영계 모니터링 로그 |
| 공유 방식 | Redmine·메신저를 통해 발생 조건과 영향 범위를 개발 담당자·관련 업무 담당자에게 공유 |

## Precondition

- 자동차보험 계약의 보험기간 개시일이 도래하지 않았다.
- 해당 계약을 모바일 웹·모바일 앱에서 조회할 수 있다.
- 실시간 단기운전자 특약 메뉴에 진입할 수 있다.

## Steps to Reproduce

다음 절차는 테스트계에서 수행했다.

1. 모바일 웹 또는 모바일 앱에서 실시간 단기운전자 특약 가입 화면에 진입한다.
2. 보험 효력이 시작되지 않은 자동차보험 계약을 선택한다.
3. 특약 가입 화면으로 진행할 수 있는지 확인한다.
4. 보험료를 계산하고 결제를 진행한다.
5. 배서계약 생성 여부와 기간계 배서내역을 확인한다.

## Expected Result

- 보험 효력 개시 전 계약은 실시간 단기운전자 특약 가입 대상에서 제외되거나 적절한 안내와 함께 신청이 차단돼야 한다.
- 보험료 결제가 실행되지 않아야 한다.
- 배서계약과 기간계 배서내역이 생성되지 않아야 한다.

## Actual Result

### 고객 문의에서 확인한 내용

- 고객이 보험 효력이 시작되지 않은 계약에서 실시간 단기운전자 특약을 실제로 결제한 사실을 확인했다.

### 테스트계에서 직접 확인한 내용

- 모바일 웹·모바일 앱에서 동일 조건을 재현했다.
- 보험료 결제까지 완료됐다.
- 배서계약이 생성됐고 기간계에서 배서내역이 조회됐다.

### 운영계에서 직접 확인한 내용

- 모바일 웹·모바일 앱에서 효력 개시 전 계약으로 특약 가입이 가능한 상태를 결제 직전까지 재현했다.
- 운영계에서는 실제 결제를 진행하지 않았다.

## 결함 등급

| 구분 | 판단 | 근거 |
| --- | --- | --- |
| Severity | `Major` | 고객의 실제 결제 사실을 확인했고 테스트계에서도 결제·배서계약 생성·기간계 반영까지 재현됨 |
| Priority | `High` | 자동차보험 효력 개시 전에 특약 결제와 배서계약 생성이 가능하므로 효력 개시 전 계약의 신청 차단이 우선 필요함 |

> 결함 등급은 공개 포트폴리오 작성 기준으로 재구성한 판단이며 실제 사내 분류값을 의미하지 않는다.

## Potential Customer Impact

- 자동차보험 효력 개시 전에 특약 보험료가 결제되고 배서계약이 생성될 수 있다.
- 고객이 해당 특약의 보장이 유효한 것으로 인식할 수 있어 실제 보장 상태와 고객 인식이 달라질 수 있다.

위 내용은 발생 가능한 영향이며, 실제 사고나 보장 분쟁 결과를 확인한 것은 아니다.

## 수정 후 확인 결과

| 구분 | 확인 환경 | 확인 결과 |
| --- | --- | --- |
| 수정 후 재검증 | 테스트계·운영계 | 모바일 웹·모바일 앱에서 보험 효력 개시 전 계약의 실시간 단기운전자 특약 신청이 차단되는지 확인했다. |
| 회귀검증 | 테스트계·운영계 | 효력이 시작된 정상 계약의 실시간 단기운전자 특약 흐름과 단기운전자 확대특약 흐름을 확인했다. |
| 운영 이관 후 확인 | 운영계 | 운영 반영 후 약 1주일간 신청 경로가 있는 모바일 웹·모바일 앱의 모니터링 로그를 확인했으며, 확인 범위에서는 동일 오류가 다시 관찰되지 않았다. |

## 확인 한계

- 최초 운영계 확인은 결제 직전까지 수행했으며 실제 결제하지 않았다.
- 수정 후 기간계 배서 결과는 확인하지 않았다.
- 개발 원인과 DB 저장값은 확인하지 않았다.

## QA Note

오류 재현 시 신청 화면 진입 여부에 그치지 않고, 자동차보험 계약의 효력 상태를 특약 신청·결제·배서계약 생성까지 연결해 확인했다. 수정 후에는 효력 개시 전 계약의 신청 차단과 효력이 시작된 정상 계약·일반 단기운전자 특약 흐름을 구분해 검증했다.
