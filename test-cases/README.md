# 자동차보험 핵심 테스트케이스

## 폴더 개요

이 폴더는 자동차보험 가입·갱신·계약변경 과정에서 실제 업무 중 확인한 사례 5건을 핵심 테스트케이스로 재구성한 문서를 관리한다.

일반적인 입력 형식이나 필수값 확인보다 보험 업무 흐름의 조건과 처리 결과, 외부 연동 예외처리, 이전 데이터 유지와 보험료·계약·배서 상태의 정합성을 중심으로 사례를 선정했다.

## 작성 기준

- 고객 문의, 운영 오류와 변경 요구사항 검증 등 확인 경위를 구분한다.
- 검증 목적, 사전조건, 단계별 기대 결과, 실제 오류와 수정 후 재검증·회귀검증·운영 이관 후 확인 결과를 구분한다.
- 테스트계·운영계와 PC 웹·모바일 등 확인 환경·채널을 구분하고, 기간계·모니터링 로그 등 실제 확인 범위를 사례별로 기록한다.
- 가입·보험료·계약·배서 상태에 영향을 주는 조건과 수정 영향 범위를 우선한다.
- 직접 확인하지 않은 개발 원인과 내부 시스템 구조는 추정하지 않는다.
- 직접 확인하지 않은 결제·계약·증권·환급 결과는 완료된 사실처럼 작성하지 않는다.

| `PRM-002`·`EVD-001`·`REN-001`·`END-001` | 별도 결함 보고서를 만들지 않고 각 상세 테스트케이스 파일에 실제 결과와 수정 후 확인 범위를 기록한다. |
