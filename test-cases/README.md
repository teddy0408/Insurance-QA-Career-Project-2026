# 자동차보험 테스트케이스

## 폴더 개요

이 폴더는 자동차보험 가입·갱신·계약변경 과정에서 실제 업무 중 확인한 고객 문의와 운영 오류를 기반으로 작성한 핵심 테스트케이스를 관리한다.

단순 기능 목록보다 보험 업무규칙, 외부 연동, 데이터 유지, 채널 간 보험료 정합성 및 수정 후 회귀검증 범위를 중심으로 구성했다.

특정 보험사의 내부 명칭, 실제 고객정보, 차량정보, 보험료, 할인율 및 외부업체명은 일반화했으며, 직접 확인하지 않은 개발 원인과 내부 시스템 구조는 작성하지 않았다.

## 작성 기준

- 실제 고객 문의 또는 운영 오류를 기반으로 작성했다.
- 정상 업무규칙과 실제 오류를 구분했다.
- 테스트계·운영계에서 직접 확인한 범위만 작성했다.
- 오류 전달 내용과 수정 후 직접 재검증한 범위를 구분했다.
- 확인하지 않은 개발 원인과 내부 시스템 구조는 추측하지 않았다.
- 일반적인 필수값 검증보다 보험 업무규칙과 후속 계약정보에 영향을 주는 사례를 우선했다.
- 사례 개수를 맞추기 위해 면접에서 설명하기 어려운 사례를 추가하지 않았다.
