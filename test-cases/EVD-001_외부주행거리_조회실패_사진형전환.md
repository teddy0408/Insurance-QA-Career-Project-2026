# EVD-001. 외부 주행거리 조회 실패 시 사진형 마일리지 특약 전환

## 개요

| 항목 | 내용 |
| --- | --- |
| 확인 경위 | 고객 문의 후 오류 재현 |
| 검증 목적 | 외부 주행거리 조회 실패 후 사진형 마일리지 특약 전환과 후속 가입 흐름 확인 |
| 대상 흐름 | 테스트계: 갱신가입 → 외부 주행거리 조회 실패 → 사진형 전환 → 사진등록·정산 절차 → 청약내용 확인 → 보험료 결제·가입 완료 / 운영계: 외부기관 주행거리 정보 미제공 조건에서 사진형 전환·사진등록 화면 표시까지 확인 |
| 검증 관점 | 외부 연동 예외 처리·대체 흐름 |
| 확인 환경·채널 | 테스트계·운영계 / PC 웹·모바일 웹·모바일 앱 |
| 공유 방식 | Redmine·메신저 |

## 사전조건

- 전년도 계약에 커넥티드 마일리지 특약이 가입돼 있다.
- 갱신 시 다음 외부 주행거리 조회 실패 조건을 각각 확인할 수 있다.
  - 커넥티드 서비스가 해지된 조건
  - 외부기관에서 주행거리 정보를 제공하지 않는 조건
- 외부 조회 실패 시 사진형 마일리지 특약으로 전환할 수 있다.
- 사진은 가입 후에도 등록할 수 있으므로, 가입 과정에서 사진을 등록하지 않아도 다음 단계로 진행할 수 있다.

## 테스트 절차 및 기대 결과

아래 절차는 테스트계 검증 범위다. 커넥티드 서비스 해지와 외부기관 주행거리 정보 미제공 조건을 각각 확인했으며, 운영계에서 확인한 조건과 범위는 ‘수정 후 확인’에 별도로 기재했다.

| 단계 | 테스트 절차 | 기대 결과 |
| --- | --- | --- |
| 1 | 커넥티드 마일리지 특약 가입계약으로 갱신을 시작한다. | 기존 특약정보가 정상적으로 조회된다. |
| 2 | 외부 주행거리 조회를 실행한다. | 조회 실패 결과와 안내 팝업이 표시된다. |
| 3 | 조회 실패 팝업을 확인한다. | 커넥티드형 특약이 해제되고 사진형 마일리지 특약으로 전환된다. |
| 4 | 전환 직후 화면과 후속 절차를 확인한다. | 사진등록 화면이 즉시 표시되고 사진등록·정산 절차가 순서대로 제공된다. |
| 5 | 적용 특약과 청약내용을 확인하고 보험료 결제부터 가입 완료까지 진행한다. | 사진형 특약만 청약내용에 반영되고 결제 단계에서 보험료를 확인한 후 가입이 완료된다. |
| 6 | 기간계와 모니터링 로그를 확인한다. | 사진형 특약 전환 상태와 처리 결과가 화면 결과와 일치한다. |

## 실제 결과

외부 조회 실패 후 커넥티드형은 해제되고 사진형으로 전환됐지만, 사진등록 화면이 즉시 표시되지 않았다. 이전 단계로 돌아온 뒤에야 사진등록 화면이 표시됐다.

사진은 가입 후에도 등록할 수 있어 사진 미등록 상태의 다음 단계 진행은 수정 전후 모두 가능했다. 이 사례의 결함은 사진 미등록 진행이 아니라, 사진형 전환 직후 사진등록 화면이 표시되지 않는 문제다.

## 수정 후 확인

| 구분 | 확인 환경 | 확인 결과 |
| --- | --- | --- |
| 수정 후 재검증 | 테스트계 | 커넥티드 서비스 해지와 외부기관 주행거리 정보 미제공 조건에서 조회 실패 팝업, 커넥티드형 해제, 사진형 전환과 사진등록 화면 즉시 표시를 확인했다. |
| 회귀검증 | 테스트계 | 사진등록·정산 절차, 커넥티드형과 사진형의 동시 적용 방지, 청약내용과 보험료 결제·가입 완료를 확인했다. 기간계와 모니터링 로그의 처리 결과도 대조했다. |
| 운영 이관 후 확인 | 운영계 | PC 웹·모바일 웹·모바일 앱에서 외부기관 주행거리 정보 미제공 조건을 확인하고, 사진형 마일리지 특약 전환과 사진등록 화면 표시까지 확인했다. |

## QA 판단

외부 조회 실패 여부만 확인하지 않고, 커넥티드형 해제·사진형 전환·사진등록과 후속 가입 흐름이 정상 순서로 연결되는지 확인했다.
