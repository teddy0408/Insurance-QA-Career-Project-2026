# REN-001. 계약변경 후 갱신 시 반려동물 등록번호 누락으로 보험료 계산 불가

## 개요

| 항목 | 내용 |
| --- | --- |
| 확인 경위 | 고객 문의 후 오류 재현 |
| 검증 목적 | 부속품 추가·삭제 및 차량대체 배서 후 반려동물 등록번호 유지와 갱신보험료 계산 확인 |
| 대상 흐름 | 계약변경 → 갱신가입 → 반려동물 등록번호 승계 → 보험료 계산 → 청약내용 확인 → 결제·가입 완료 |
| 검증 관점 | 갱신 데이터 유지·상태 정합성 |
| 확인 환경·채널 | 테스트계·운영계 / PC 웹·모바일 웹·모바일 앱 |
| 공유 방식 | Redmine·메신저 |

## 사전조건

- 반려동물 특약이 가입된 계약이다.
- 유효한 반려동물 등록번호가 저장돼 있다.
- 한 마리 또는 여러 마리의 반려동물이 등록돼 있다.
- 전 계약에 차량대체·부속품 추가·부속품 삭제 중 하나의 배서가 반영돼 있다.

## 테스트 절차 및 기대 결과

| 단계 | 테스트 절차 | 기대 결과 |
| --- | --- | --- |
| 1 | 한 마리 또는 여러 마리의 반려동물 등록번호가 저장된 계약을 확인한다. | 각 반려동물의 등록번호가 정상적으로 조회된다. |
| 2 | 차량대체·부속품 추가·부속품 삭제 조건별로 배서를 진행한다. | 각 배서 이후에도 기존 반려동물 등록번호가 유지된다. |
| 3 | 배서가 반영된 계약으로 갱신가입을 시작한다. | 기존 반려동물 등록번호가 갱신 설계에 정상적으로 승계된다. |
| 4 | PC 웹·모바일 웹·모바일 앱에서 보험료를 계산한다. | 추가특약 오류 없이 보험료가 정상적으로 계산된다. |
| 5 | 기간계의 갱신 청약정보와 모니터링 로그를 확인한다. | 갱신 청약정보와 처리 로그에 반려동물 등록번호가 정상적으로 반영된다. |
| 6 | 청약내용을 확인하고 결제·가입 완료까지 진행한다. | 반려동물 등록번호가 유지된 상태로 정상적으로 결제되고 계약이 생성된다. |

## 실제 결과

고객이 자동차보험 갱신 중 보험료를 계산하면 `추가특약을 확인해주세요.` 팝업이 표시되고 보험료 계산 결과가 나오지 않는다고 문의했다.

개발자에게 확인을 요청한 결과, 전 계약에 부속품 추가 배서가 반영되는 과정에서 반려동물 등록번호가 누락됐고, 그 상태가 갱신 설계로 이어진 조건이라는 답변을 받았다. 반려동물 특약 선택과 반려동물 유형은 유지됐지만 등록번호만 누락돼 있었다.

부속품 추가와 같은 계약변경 흐름에서 발생하는 문제인지 확인하기 위해 차량대체와 부속품 삭제 조건까지 검증 범위를 확장했다. 테스트 결과 차량대체와 부속품 삭제 조건에서도 반려동물 등록번호가 누락되는 동일 현상을 재현했다. 한 마리와 여러 마리 등록 조건에서도 동일하게 확인했다.

PC 웹·모바일 웹·모바일 앱과 테스트계·운영계에서 보험료 계산 오류를 확인했다. 기간계에서는 해당 갱신 청약번호에 반려동물 등록번호가 없었고, 모니터링 로그에서도 등록번호가 적재되지 않은 것을 확인했다.

화면에서 특약과 반려동물 유형을 확인하고 등록번호를 다시 입력해 저장하면 보험료 계산이 가능했다.

## 수정 후 확인

| 구분 | 확인 환경 | 확인 결과 |
| --- | --- | --- |
| 수정 후 재검증 | 테스트계 | 부속품 추가·삭제와 차량대체 조건에서 반려동물 등록번호가 갱신 설계에 정상적으로 유지되고, `추가특약을 확인해주세요.` 팝업이 발생하지 않으며 보험료가 정상적으로 계산되는지 확인했다. |
| 조건별 확인 | 테스트계 | 한 마리와 여러 마리 등록 조건에서 반려동물 등록번호 유지 여부를 각각 확인했다. |
| 회귀검증 | 테스트계 | PC 웹·모바일 웹·모바일 앱에서 보험료 계산, 청약내용 확인, 결제·가입 완료까지 확인했다. 기간계의 계약·보험료·반려동물 등록번호와 모니터링 로그의 처리 결과도 대조했다. |
| 운영 이관 후 확인 | 운영계 | 운영 이관 직후 동일 계약으로 직접 결과를 확인하기 어려워, 약 1주일 동안 동일 조건으로 갱신한 후속 계약을 확인했다. 한 마리·여러 마리 조건에서 기간계와 모니터링 로그의 반려동물 등록번호 유지 여부를 확인했다. |

## QA 판단

최초 고객 문의와 개발자 확인을 통해 부속품 추가 배서 후 반려동물 등록번호가 누락되는 조건을 확인했다. 동일한 계약변경 흐름에서 영향이 발생할 가능성을 고려해 차량대체와 부속품 삭제까지 검증 범위를 확장했고, 두 조건에서도 같은 오류를 재현했다.

한 마리와 여러 마리 등록 조건을 구분해 확인하고, 화면의 팝업뿐 아니라 기간계 갱신 청약정보와 모니터링 로그의 등록번호 적재 여부까지 대조했다.
