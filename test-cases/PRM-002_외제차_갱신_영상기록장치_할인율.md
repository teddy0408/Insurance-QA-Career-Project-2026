# PRM-002. 외제차 갱신 시 자동 승계된 내장형 영상기록장치의 할인율·보험료 정합성

## 개요

| 항목 | 내용 |
| --- | --- |
| 확인 경위 | 고객 문의 기반 오류 확인 |
| 검증 목적 | 자동 승계된 장치 유형과 적용 할인율·보험료의 정합성 확인 |
| 대상 흐름 | 갱신가입 시작 → 장치정보 자동 승계 → 보험료 계산 → 청약내용 확인 → 결제·가입 완료 |
| 검증 관점 | 자동 승계·보험료 정합성·회귀검증 |
| 확인 환경·채널 | 테스트계·운영계 / PC 웹·모바일 |
| 공유 경로 | Redmine·메신저 |

## 사전조건

- 전년도 계약에 내장형 영상기록장치 할인특약이 가입돼 있다.
- 특정 외제차량의 갱신가입 조건이다.
- 전년도 장치정보가 갱신 화면으로 자동 승계된다.
- 일반형과 내장형 영상기록장치에 서로 다른 할인율이 적용된다.

## 테스트 절차 및 기대 결과

| 단계 | 테스트 절차 | 기대 결과 |
| --- | --- | --- |
| 1 | 특정 외제차의 갱신가입을 시작한다. | 전년도 내장형 장치정보가 자동 승계된다. |
| 2 | 장치 유형을 다시 선택하지 않고 보험료를 계산한다. | 내장형 할인율과 보험료가 적용된다. |
| 3 | PC 웹·모바일과 기간계 결과를 비교한다. | 장치 유형·할인율·보험료가 일치한다. |
| 4 | 내장형 장치를 수동으로 다시 선택해 재계산한다. | 자동 승계 상태와 수동 선택 상태의 결과가 일치한다. |
| 5 | 청약내용 확인부터 결제·가입 완료까지 진행한다. | 내장형 할인율과 보험료가 유지된 상태로 가입이 완료된다. |

## 실제 결과

특정 외제차의 갱신가입에서 내장형 장치정보가 자동 승계되면 PC와 모바일에 일반형 할인율이 적용됐다. 기간계에는 내장형 할인율이 적용돼 온라인 갱신보험료와 기간계 보험료가 일치하지 않았다.

내장형 장치를 수동으로 다시 선택하면 정상 할인율이 적용됐다. 신규가입에서는 국산차와 외제차 모두 정상적으로 계산됐다.

## 수정 후 확인

| 구분 | 확인 환경 | 확인 결과 |
| --- | --- | --- |
| 수정 후 재검증 | 테스트계 | 특정 외제차 갱신가입에서 내장형 장치정보·할인율·보험료가 정상 적용되는지 확인하고 자동 승계와 수동 재선택 결과를 비교했다. |
| 회귀검증 | 테스트계 | 신규·갱신, 국산차·외제차, 일반형·내장형 조건을 조합했다. PC 웹·모바일·기간계의 장치 유형·할인율·보험료와 청약내용을 대조하고 결제·가입 완료까지 확인했다. |
| 운영 이관 후 확인 | 운영계 | 신규·갱신 조건에서 PC 웹·모바일·기간계의 장치 유형·할인율·보험료가 일치하는지 확인했다. |

## QA 판단

자동 승계 화면의 장치정보 표시뿐 아니라 수동 재선택 결과를 비교 기준으로 사용해 장치 유형·할인율·보험료의 정합성을 확인했다.
