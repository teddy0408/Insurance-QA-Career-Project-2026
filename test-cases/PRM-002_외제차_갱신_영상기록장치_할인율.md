# PRM-002. 외제차 갱신 시 자동 승계된 내장형 영상기록장치의 할인율·보험료 정합성

## 개요

| 항목 | 내용 |
| --- | --- |
| 확인 경위 | 고객 문의 후 오류 재현 |
| 검증 목적 | 외부 부속조회 대상인 외제차 갱신에서 자동 승계된 내장형 영상기록장치에 맞는 할인율·보험료 적용 확인 |
| 대상 흐름 | 테스트계: 갱신가입 시작 → 장치정보 자동 승계 → 보험료 계산 → 청약내용 확인 → 결제·가입 완료 / 운영계: 수정 반영 후 해당 오류 조건의 보험료 계산까지 확인 |
| 검증 관점 | 갱신 데이터 자동 승계·보험료 계산 정합성 |
| 확인 환경·채널 | 테스트계·운영계 / PC 웹·모바일 웹·모바일 앱 |
| 공유 경로 | Redmine·메신저 |

## 사전조건

- 전년도 계약에 내장형 영상기록장치 할인특약이 가입돼 있다.
- 외부 부속조회 대상인 외제차의 갱신가입 조건이다.
- 전년도 장치정보가 갱신 화면으로 자동 승계된다.
- 일반형과 내장형 영상기록장치에 서로 다른 할인율이 적용된다.

## 테스트 절차 및 기대 결과

| 단계 | 테스트 절차 | 기대 결과 |
| --- | --- | --- |
| 1 | 외부 부속조회 대상인 외제차의 갱신가입을 시작한다. | 전년도 내장형 장치정보가 자동 승계된다. |
| 2 | 장치 유형을 다시 선택하지 않고 보험료를 계산한다. | 내장형 할인율과 보험료가 적용된다. |
| 3 | PC 웹·모바일 웹·모바일 앱과 기간계 결과를 비교한다. | 장치 유형·할인율·보험료가 일치한다. |
| 4 | 내장형 장치를 수동으로 다시 선택해 재계산한다. | 자동 승계 상태와 수동 선택 상태의 결과가 일치한다. |
| 5 | 청약내용 확인부터 결제·가입 완료까지 진행한다. | 내장형 할인율과 보험료가 유지된 상태로 가입이 완료된다. |

## 실제 결과

고객센터에서 갱신보험료 차이에 대한 확인 요청을 받아 영상기록장치의 할인 적용 상태를 확인했다. 차량 조건을 바꿔 비교하면서 확인한 국산차 갱신 조건에서는 오류가 없었고, 외부 부속조회 대상인 외제차 갱신의 내장형 영상기록장치 자동 승계 조건에서 오류를 재현했다.

해당 조건에서는 화면에 내장형 영상기록장치 정보가 표시됐지만 일반형 할인율과 보험료가 적용됐다. 기간계에서는 내장형 할인보험료가 적용돼 홈페이지 갱신보험료와 차이가 발생했다.

내장형 장치를 수동으로 다시 선택하면 정상 할인율과 보험료가 적용됐다. 신규가입에서는 확인한 국산차와 외제차 조건 모두 정상적으로 계산됐다.

확인한 발생 조건과 비교 결과를 바탕으로 해당 조건의 할인 적용 오류에 대한 수정 요청을 전달했다.

| 운영 이관 후 확인 | 운영계 | 외제차 갱신의 내장형 영상기록장치 자동 승계 조건에서 내장형 할인율과 보험료가 정상 적용되는지 보험료 계산까지 확인했다. |

## QA 판단

고객 문의의 보험료 차이를 재현하고, 국산차·외제차와 신규·갱신 조건을 비교해 오류가 발생하는 범위를 좁혔다.

자동 승계 화면에 내장형 장치정보가 표시되는 것만으로 정상이라고 판단하지 않았다. 수동 재선택 결과와 기간계 보험료를 비교 기준으로 사용해 장치 유형·할인율·보험료의 정합성을 확인했다.

확인한 조건을 수정 요청으로 전달했으며, 개발 코드상의 근본 원인을 직접 확인하거나 QA 프로세스를 변경한 사례는 아니다.
