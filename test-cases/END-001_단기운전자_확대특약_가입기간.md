# END-001. 단기운전자 확대특약 가입 기간 유효성

## 개요

| 항목 | 내용 |
| --- | --- |
| 확인 경위 | 변경 요구사항 검증 중 오류 확인 |
| 검증 목적 | 기존 특약 가입 기간 중복과 자동차보험 계약 개시일 전 기간을 포함한 신청 차단 확인 |
| 대상 흐름 | 가입 챗봇 진입 → 차량번호 입력 → 이용 시작일자 입력 → 이용 기간 입력 → 보험료 계산 → 결제 |
| 검증 관점 | 기간 유효성·경계 조건 |
| 확인 환경·채널 | 테스트계·운영계 / 모바일 웹·모바일 앱 |
| 공유 방식 | 팀 단체 채팅방 |

## 사전조건

### 조건 A. 기존 특약과 기간이 겹치는 신청

- 대상 자동차보험 계약이 유효한 상태다.
- 동일 계약에 단기운전자 확대특약이 이미 가입돼 있다.
- 기존 특약은 결제가 완료되고 효력이 발생한 상태다.
- 기존 특약기간은 `T ~ T+4`다.

### 조건 B. 자동차보험 계약 개시 전 기간을 포함한 신청

- 자동차보험 계약 개시일은 `P`다.
- 테스트 시점에는 자동차보험 계약의 효력이 아직 개시되지 않은 상태다.
- 해당 계약에는 차량번호가 등록돼 있으며 모바일에서 정상 조회할 수 있다.

> `T`와 `P`는 실제 계약을 식별하지 않도록 일반화한 기준일이다.

## 테스트 절차 및 기대 결과

### 조건 A. 기존 특약과 기간이 겹치는 신청

| 단계 | 테스트 절차 | 기대 결과 |
| --- | --- | --- |
| 1 | 모바일 웹 또는 모바일 앱에서 가입 챗봇에 진입하고 기존 특약이 가입된 계약의 차량번호를 입력한다. | 이용 시작일자 입력 단계로 진행된다. |
| 2 | 기존 특약기간 `T ~ T+4`와 겹치는 `T+2 ~ T+4`를 입력한다. | 기간 중복 안내와 함께 신청이 차단된다. |
| 3 | 기존 특약기간과 겹치지 않는 `T+5 ~ T+7`을 입력한다. | 보험료가 계산되고 결제 단계로 진행된다. |

### 조건 B. 자동차보험 계약 개시 전 기간을 포함한 신청

| 단계 | 테스트 절차 | 기대 결과 |
| --- | --- | --- |
| 1 | 모바일 웹 또는 모바일 앱에서 단기운전자 확대특약 가입 챗봇에 진입한다. | 차량번호 입력 단계가 표시된다. |
| 2 | 아직 개시되지 않은 계약의 차량번호를 입력한다. | 이용 시작일자 입력 단계로 진행된다. |
| 3 | 자동차보험 계약 개시일 전 날짜가 포함된 `P-1 ~ P+1`을 입력한다. | 계약 개시 전 기간 포함 안내와 함께 신청이 차단된다. |
| 4 | 자동차보험 계약 개시일 이후의 유효한 시작일자와 이용 기간을 입력한다. | 보험료가 정상적으로 계산된다. |
| 5 | 계산된 보험료를 확인하고 다음 단계로 진행한다. | 결제 단계로 정상 진행된다. |

## 실제 결과

### 조건 A. 기존 특약과 기간이 겹치는 신청

- 기존 배서내역에 `T ~ T+4`의 특약 가입기간이 표시됐다.
- 기존 특약기간과 겹치는 `T+2 ~ T+4`를 입력했지만 신청이 차단되지 않았다.
- 중복 신청의 최종 결제는 확인하지 않아 신청이 차단되지 않은 결과까지만 기록했다.

### 조건 B. 자동차보험 계약 개시 전 기간을 포함한 신청

- 아직 개시되지 않은 계약의 차량번호로 다음 단계에 진행할 수 있었다.
- 계약 개시일 전 날짜가 포함된 `P-1 ~ P+1`을 입력했지만 신청이 차단되지 않았다.
- 테스트계에서 보험료 결제까지 완료됐다.

조건 A는 테스트 요청에 포함된 조건이고, 조건 B는 가입 기간 검증 과정에서 추가로 확인한 경계 조건이다. 두 조건 모두 모바일에서 확인했으며 PC 웹에서는 동일 조건을 확인하지 않았다.

## 수정 후 확인

| 구분 | 확인 환경 | 확인 결과 |
| --- | --- | --- |
| 수정 후 재검증 | 테스트계 | 모바일 웹·모바일 앱에서 기존 특약기간과 겹치는 신청과 자동차보험 계약 개시일 전 날짜를 포함한 신청이 차단되고 조건별 안내가 표시되는지 확인했다. |
| 회귀검증 | 테스트계 | 유효한 정상 기간에서 보험료 계산과 결제를 완료하고 기간계에서 배서내역을 확인했다. |
| 운영 이관 후 확인 | 운영계 | 모바일 웹·모바일 앱에서 기존 특약기간과 겹치지 않는 정상 조건으로 보험료를 확인하고 결제 직전까지 진행했다. |

## QA 판단

테스트 요청의 기간 중복 조건에서 자동차보험 계약 개시일 경계까지 범위를 확장했다. 비정상 기간의 신청 차단과 정상 기간의 보험료 계산·결제 흐름을 구분해 확인했다.
